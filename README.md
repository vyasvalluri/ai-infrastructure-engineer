# AI Infrastructure Engineer

A practical learning, lab, and portfolio repository for progressing from AI Platform Engineer to AI Infrastructure Engineer and AI Platform Architect.

This repository is designed for an experienced software and infrastructure engineer. It focuses on the systems that make AI workloads reliable and operable: GPU infrastructure, inference, distributed compute, observability, automation, troubleshooting, and architecture. It is not an ML research or generic AI application-development course.

## Learning Path

Follow the ordered phases in [ROADMAP.md](ROADMAP.md). The `docs/` tree will hold the learning modules, while `labs/`, `infrastructure/`, `manifests/`, `scripts/`, and `dashboards/` will hold practical exercises and implementation assets. [ARCHITECTURE.md](ARCHITECTURE.md) records the system model that connects these topics. [PROGRESS.md](PROGRESS.md) is the project status tracker.

## Scope

- Build practical knowledge of AI factories, Linux, containers, GPUs, CUDA, GPU operations, networking, inference, distributed compute, observability, and infrastructure automation.
- Connect the modules through an end-to-end Mini AI Factory portfolio project.
- Develop troubleshooting, architecture-design, interview, and career-readiness material.
- Use Kubernetes where workloads require it, assuming the learner's separate Kubernetes study. Kubernetes is not a standalone module here; any required explanation should be limited to the minimum needed and note that Kubernetes fundamentals are covered separately through KodeKloud.
